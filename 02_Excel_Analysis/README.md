# Exploratory Data Analysis using Excel

## Overview

This folder contains the Excel-based Exploratory Data Analysis (EDA) performed on the cleaned Cafe Sales dataset.

The analysis was performed to understand overall sales performance, product performance, transaction patterns, and other business-related metrics.

## Analysis Performed

- KPI analysis
- Total Sales analysis
- Total Quantity analysis
- Transaction analysis
- Average Unit Price analysis
- Average Transaction Value analysis
- Product-wise sales analysis
- Product-wise quantity analysis
- Payment method analysis
- Location-wise analysis
- Pivot table analysis
- Charts and visualizations
- Outlier and anomaly analysis
