# Interactive Power BI Dashboard

## Overview

This folder contains the interactive Power BI dashboard developed using the cleaned Cafe Sales dataset.

The dashboard was created to transform the analyzed data into interactive visualizations and business insights.

## Dashboard Features

The dashboard includes:

- Total Sales KPI
- Total Quantity KPI
- Total Transactions KPI
- Average Unit Price
- Average Transaction Value
- Product-wise Sales Analysis
- Product-wise Quantity Analysis
- Payment Method Analysis
- Location-wise Analysis
- Monthly Sales Trend
- Interactive Slicers and Filters

## Data Preparation

The dataset used for the dashboard was cleaned and prepared using PostgreSQL before being imported into Power BI.

## Power BI Techniques Used

- Power Query
- Data Cleaning
- Data Transformation
- Data Modeling
- DAX Measures
- KPI Cards
- Charts and Visualizations
- Slicers
- Interactive Dashboard Design
